# 🛒 DSH 插件市场

**给 DeepSeek Harness 用的插件商城** —— 不用再满世界搜插件了，所有好插件都在这里，一眼看清、放心选用。

## 🌐 在线逛市场

👉 **https://yurewright.github.io/dsh-plgstore/**

打开就能逛，不需要安装任何东西：

- **1800+ 个插件**，覆盖聊天机器人、图像/视频、语音、记忆、用量管理、界面美化、开发工具……
- **每个插件都有"体检报告"**：是干嘛的、会不会碰你的隐私、装完要做什么——大白话讲清楚，分三档：😊 放心用 / 🤔 留个心眼 / ⚠️ 别急着装
- **想找什么直接搜**：按名称、简介、报告内容全文检索；还能按分类、安装方式、信任档筛选，按热度/评分排序
- **每天中午 13:00 自动更新**：新上架的插件当天就能看到

## 📰 每日日报

👉 **https://yurewright.github.io/dsh-plgstore/daily.html**

每天 13:00 自动出刊，三份榜单一网打尽：

- 🆕 **新推出的插件**：今天上架了什么
- 🔥 **涨星最快的插件**：最近谁最受关注（基于每日数据快照统计）

每条都附**直达链接 + 简介 + AI 功能介绍 + 放心档位**，逛市场前列份日报，不错过任何好插件。

## 🚀 快速开始

1. 打开 **https://yurewright.github.io/dsh-plgstore/** 逛插件；
2. 看中插件 → 复制它的安装口令（npm / git 两种）；
3. 在 DSH 里执行：`dsh plugin --profile web add <口令>`

> 💡 一键安装按钮正在开发中——以后在市场里点一下就能装。

- 数据每天中午自动更新，以网页为准。
